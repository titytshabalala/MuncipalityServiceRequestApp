# Municipal Services Application (MuncipalityServiceRequestApp)

A C# .NET Framework Windows Forms desktop application designed for residents of the City of Tshwane to report service delivery issues, track request statuses, and discover local events and announcements.

---

## Requirements

- **Operating System:** Windows 10 or Windows 11
- **IDE:** Visual Studio 2019 or later (Community / Professional)
- **Framework:** .NET Framework 4.7.2 or later (installed via Visual Studio's ".NET desktop development" workload)

---

## How to Compile and Run

1. Open **MuncipalityServiceRequestApp.sln** in Visual Studio.
2. Wait for Visual Studio to load the project solution and resolve namespaces.
3. Press **F5** (or click **Start**) to build and execute the application.
   - *Alternative:* Go to **Build > Build Solution** (`Ctrl+Shift+B`), then run `MuncipalityServiceRequestApp.exe` directly from `bin\Debug\`.
4. **Dependencies:** Uses standard .NET Framework Windows Forms components and custom in-memory data structures. No external database configuration or external packages are required.

---

## How to Use the Application

1. **Main Menu (`Form1.cs`)** — Features three primary modules:
   - **Report Issues** — Active & Fully Functional.
   - **Local Events and Announcements** — Active & Fully Functional.
   - **Service Request Status** — Active & Fully Functional.

2. **Report Issues (`ReportIssueForm.cs`)**:
   - Enter **Location**, select a **Category** (Sanitation, Roads, Water & Utilities, Electricity, Public Safety, Other), and provide a detailed **Description**.
   - Optionally attach supporting photos or documents via the file picker.
   - Real-time progress bar guides you through form completion. Click **Submit** to log the issue and generate a unique reference ID.

3. **Local Events and Announcements (`LocalEventsForm.cs`)**:
   - Filter announcements using the **Search Keyword**, **Category**, or **Location** dropdowns.
   - View top personalized recommendations generated by `RecommendationEngine.cs` based on your search frequency and historical views.
   - Live **Urgent Announcements Banner** displays critical high-priority notices at a glance.
   - Click on any event row to log it in your **Recently Viewed** history list.

4. **Service Request Status**:
   - Track live request statuses and inspect underlying service request priority structures across Tshwane regions.

## Project Structure & Architecture

| File | Purpose |
|---|---|
| `Form1.cs` | Central dashboard and navigation hub linking all three application modules. |
| `ReportIssueForm.cs` | Form UI for submitting municipal issues, handling file attachments, and live progress validation. |
| `Issue.cs` / `IssueRepository.cs` | Data model and in-memory repository managing reported service issues. |
| `LocalEventsForm.cs` | Form UI for filtering, searching, and displaying municipal events and announcements. |
| `MunicipalEvent.cs` | Model representing community events, public notices, and priority levels. |
| `EventRepository.cs` | Storage repository utilizing sorted collections and hash tables for $O(1)$ and $O(\log N)$ event lookups. |
| `RecommendationEngine.cs` | Algorithmic logic that analyzes user search history to populate the "Recommended for You" section. |
| `SearchHistoryService.cs` | Tracks recent user queries, viewed event IDs, and category lookup counts for recommendation scoring. |
| `AppTheme.cs` | Centralized design layout engine providing consistent fonts, Tshwane municipality colour branding, and custom control styling. |

---

## Technical Notes

- Data is stored **in-memory** for the duration of the application session.
- Event lookup and filtering leverage optimized data structures (Dictionary indexing by Category and Date) to avoid full array scans.
